# Evidence-backed node routes

Use the public node library at `docs/ue5/NODE_LIBRARY.md` when the request concerns the inspected two-project case.

Evidence boundaries:

- Verified client nodes include address text conversion, TCP connect/send, connection and receive delegates, pressed/released controls, camera switching, drone propeller rotation, and camera-follow rotation.
- The observed example port and numeric command set are project examples, not universal defaults.
- The exact desktop server graph and numeric command mapping remain unverified.
- A provider credential was found in a Blueprint default. Never repeat it. Require revocation and recommend a controlled gateway.

When explaining a graph, provide: trigger, execution chain, important pins, ownership, failure guards, safer reconstruction, and required packaged test.
