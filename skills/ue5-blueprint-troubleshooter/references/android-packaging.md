# Android packaging

Read `../../../docs/ue5/ANDROID_PACKAGING.md` for packaging and test details.

Before proposing a fix, collect the UE patch version, packaging configuration, SDK/NDK/JDK versions, target SDK, ABI, package identity, signing mode, plugin platform support, exact build error, and whether the failure occurs at package, install, launch, or runtime.

Do not copy historical Android versions or permissions into a new release without checking current official requirements. Never request or expose signing secrets.
