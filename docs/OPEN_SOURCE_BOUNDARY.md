# Public release boundary

Allowed content includes original guidance, generic diagrams, invented minimal reproductions, redacted Blueprint text exports, and project files created solely for this repository.

Do not publish marketplace assets, proprietary project content, client names, credentials, machine paths, private logs, or `.uasset`/`.umap` files until ownership, dependencies, plugins, soft references, and redistribution rights are verified.

When a real case cannot be shared safely, publish a generic explanation and independently recreated minimal reproduction.
