## Blueprint explanation

Describe:

- entry event;
- execution path;
- important data pins;

## Root cause

Record only after it is demonstrated. Separate the confirmed cause from contributing conditions.

## Fix and verification

List the minimal change, tests performed, engine modes tested, and remaining limitations.

## Shareability check

Confirm that screenshots, node exports, asset names, paths, and logs contain no private or third-party material.
